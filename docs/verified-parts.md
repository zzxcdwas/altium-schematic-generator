# 官方库件热点实测表

> **读法**：所有坐标都以 `place_pin()` 锚定的**编号最小的那个引脚**为原点 `(0,0)`，
> 其余引脚是相对它的偏移量。单位 = 1/100 英寸（10 mil）。
>
> 例：`RES rot=270 → pin2=(0,40)` 表示竖放时 2 号脚在 1 号脚**正下方 40** 处。
>
> 数据由 `tools/probe_library_hotspots.py` 实跑生成，可复现。

## 14-74系列TTL芯片.SchLib —— 74LS47（BCD→七段译码）

|---|---|---|---|
| 16 (VCC) | (40,-20) | 13 | (80,10) |

| 4 | (-20,10) | 11 | (80,30) |

## 换一个新元件怎么办

不要手算，跑一遍探测器：

```bash
python tools/probe_library_hotspots.py "库文件名.SchLib" 元件名 --rot 0 90 180 270
```

拿到真实热点再写布局代码。
